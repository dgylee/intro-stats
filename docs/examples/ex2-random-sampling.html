Randomness (sampling and otherwise)

Randomness will have important ramifications in statistics, both in terms of representativeness and reducing bias, although most discussions will be limited and involve a lot of handwaving. Nonetheless, when things are done “at random”, then we should not (for example) be able to predict with 100% certainty an outcome.

# Re-running the code so we get the same value

We don’t need to get into the specifics, but setting the seed to a specific number creates reproducible results (i.e. no set.seed, the results will change but with it, you’ll get the same results no matter how many times you hit the ▶ Run Code button).

Visualization (heat map)

If you have repeatedly hit the ▶ Run Code button (sans set.seed), then you’ll notice that the 10 numbers have changed repeatedly. Importantly, if we are truly randomly sampling 10 numbers from a set of 20, then if we visualized which of the 10 numbers (from our set of 20) are selected over and over again, there should be no obvious patterns. To visualize this, a heatmap (a data visualization that converts a matrix of data into colors) is a great option - you can learn more in our DSCI204 class.

Similar to the code above, we can play around with the following chunk of code that uses a custom function created for this purpose random_heatmap, where the only inputs are (1) how many trials (n_trials) and (2) the values (values) we are selecting from. By default, the inputs are 10 trials and selecting from the numbers 1:20 but feel free to modify these values to see how the heatmap changes. For example, since the code will always split the data into two groups, if you swap the values to (for example) 1:30, then 15 values will be highlighted in the map.

If you play around with this, you’ll (hopefully) notice that there is no distinct pattern (i.e. it is random) and (if you want to), you can add in an option to print the frequency table of the values you are sampling from to see their frequency across the 10 trials.

random_heatmap(10, 1:20, table=TRUE)

It is worth noting that:

  • For more than 100 trials, the graph gets a bit weird and so the heatmap won’t print out and instead, you’ll the frequency table.
  • For each of the values (1:20), they “should” be observed half of the time, but that isn’t always the case; however, if you look at the frequency, you’ll (A) see some are (for example) observed more than 5 times while some are observed less than 5 times but (on average), the number of times should be around 5, and (B) if you increase the number of trials to 100, you’ll see a similar variability but they (again) hover somewhere around half (or 50 times).
